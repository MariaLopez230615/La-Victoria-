# La Victoria

Prototipo de una plataforma privada de entretenimiento familiar.

## Publicación
Este repositorio puede publicarse con GitHub Pages desde **Settings → Pages**.

## Importante
Esta versión utiliza puntos virtuales sin valor monetario. No procesa depósitos, retiros ni apuestas con dinero real. Los nombres, gráficos y recursos incluidos son originales y no pretenden representar ni estar asociados con proveedores de juegos de terceros.

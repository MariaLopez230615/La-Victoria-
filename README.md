# La Victoria V2

Versión 2 del prototipo de entretenimiento familiar para GitHub Pages.

## Incluye
- Lobby responsive para celular y PC.
- Perfil, niveles y saldo de fichas virtuales.
- Bonos virtuales y favoritos guardados en el navegador.
- Categorías, buscador y filtro por estudio ficticio.
- 10 juegos demo con nombres y recursos originales.
- Mini juego de giro con fichas virtuales.
- Soporte de demostración.
- Diseño responsive tipo plataforma de entretenimiento.

## Publicación en GitHub Pages
Subí `index.html`, `style.css` y `app.js` a la raíz del repositorio.  
Si ya tenés GitHub Pages activado desde la rama principal y `/ (root)`, el mismo enlace se actualizará automáticamente.

## Importante
Las fichas son puntos virtuales sin valor monetario. La demo no procesa depósitos, retiros ni apuestas con dinero real. Los estudios, juegos, nombres y recursos visuales de esta versión son ficticios/originales y no están asociados con proveedores de juegos de terceros.
